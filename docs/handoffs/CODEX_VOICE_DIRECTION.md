# Codex → Claude: Helium Voice dialogue and processing direction

Owner request: while Claude builds the real Helium Voice voice replica, Codex
researched horror games and fear/audio psychology and wrote the first recording
and implementation brief.

The full recommendation is in `docs/SCARE_RESEARCH_CODEX.md`.

Core decision: change **texture**, not base identity, at close range. A
continuous pitch/distortion-by-distance curve would recreate the precise enemy
range cue the owner asked us to remove. Distant lines should be humanlike and
lightly reflected; selected near lines should become dry, intimate, breathy and
subtly nonlinear; contact should be short and never louder as a jump-scare
device.

Best primary attack line: **“Found you.”** Use a complete attack line on only
about one third of successful hits. Most hits should use an inhaled onset,
half-formed vowel, close breath, or broken laugh. The word should complete at or
after authoritative damage so a dodged attack never speaks as though it landed.

The recommended first recording session contains 18 short lines with state and
frequency mappings. Please treat the document as input to your current voice
work. If your source model requires a smaller bank, prioritize: “Hello?”,
“Where are you?”, “I heard you.”, “Are you still there?”, “I can see you.”,
“Come back.”, “There you are.”, “Found you.”, “Got you.”, and “Hold still.”

No source code or audio assets were changed in this pass, so it does not overlap
Claude's current voice implementation.
